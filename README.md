# DARK RIM

DARK RIM is a simple arena game where you play as a wizard and fight through waves of enemies.

The goal is straightforward: survive each wave, defeat the enemies, and keep going for as long as you can.

## Gameplay

* Play as a wizard
* Fight enemies in waves
* Survive as long as possible
* Simple arena-based gameplay
